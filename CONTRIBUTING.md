# Rules and Regulations

No AI. Doesn't matter if you want to help out with languages that you don't speak or want to generate graphics for entries. 
Any attempt at using AI will get you banned from this repository without any second chance.

Use your own words. Only quote the novel when necessary, for example for Fang Yuan's poems.

Include your sources. I need to be able to check exactly where your information is from. 
For websites, a link to said website is necessary.
For the novel, the chapter suffices. Please do not link/ mention any inofficial websites that host the novel. 
There have been repositories shut down due to DMCA strikes, even if the strikes aren't legally accurate. I don't want to take any chances with that.

# I want to contribute in a language that is not english

Since I can't check if contributions in non english languages are accurate, all information must be present in english before it can be present in another language.
